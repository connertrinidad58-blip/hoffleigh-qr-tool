# Hoff & Leigh QR Code Tool

Create and update branded QR codes for Hoff & Leigh properties.

## Download
See the [Releases](../../releases) section to download the latest version.

## How to install
1. Download `HoffLeigh_QR_Tool.dmg` from Releases
2. Double-click the DMG file
3. **First time only:** right-click the app → Open → then go to  
   System Settings → Privacy & Security → click "Open Anyway"

## What it does
- **Create new QR codes** for new properties (enter URL, address, broker info)
- **Update existing QR codes** to the correct Hoff & Leigh brand red
